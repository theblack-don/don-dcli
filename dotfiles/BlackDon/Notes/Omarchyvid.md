
Omarchy First Look: Arch + Hyprland + Quick Shell Install, Plugins, and Unbloating
The video walks through installing Omarchy (an Arch-based Hyprland distro with its own Quick Shell), setting up a user account, and completing an encrypted install. After the first boot, the system is updated, noting Omarchy is about a month behind Arch to avoid breaking changes. The Quick Shell app launcher, keyboard-focused defaults, and settings are explored, including themes, bar positioning, fonts, and documentation links. The episode highlights Omarchy’s plugin marketplace (over 1,000 plugins), demonstrates adding and placing bar plugins like a grayscale toggle and a recently-closed app restorer, and reviews the built-in TUI package installer using yay/AUR. Web app creation is shown, and a “remove” option quickly uninstalls preinstalled apps/web apps to “unbloat” the system. Overall, Omarchy is presented as a smoother, more beginner-friendly Hyprland starting point. https://omarchy.org/
